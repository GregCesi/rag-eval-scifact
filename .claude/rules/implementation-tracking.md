# Tracking des fichiers IMPLEMENTATION

## Cocher les livrables terminés — OBLIGATOIRE

Quand un livrable (`- [ ]`) d'un fichier `IMPLEMENTATION_*.md` est complété :
1. **Cocher immédiatement** le livrable (`- [ ]` → `- [x]`)
2. **Cocher les checks `✋ Verify`** de la phase correspondante une fois tous vérifiés

Ne jamais passer à la phase suivante sans avoir coché les livrables et checks de la phase courante.
Un livrable non coché = un livrable non fait, même si le code existe.
